# Project Prompt

Build and extend a clean C++17 terminal Hangman game.

## Goals

- Keep the game playable without third-party dependencies.
- Validate input and handle repeated guesses clearly.
- Separate word selection, game state, rendering, and input logic as the project grows.
- Add tests for win, loss, repeated guesses, and invalid input behavior.

## Suggested Next Features

- Load words from a text file.
- Add difficulty levels and categories.
- Track wins and losses.
- Add a two-player mode where one player enters the secret word.
